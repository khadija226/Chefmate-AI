# 🍳 ChefMate AI

**An AI-powered international cooking assistant that turns your ingredients into delicious recipes.**

ChefMate AI understands ingredients, packaged food products, food brands, cuisines, dishes, cooking techniques, substitutions, and more — helping users decide what to cook with what they already have.

## 🚀 Live Demo

🔗 **[https://chefmate-ai-by-khadija.streamlit.app/)**

### 🔑 How to Use

1. Open the Live Demo.
2. Enter your own OpenAI API key.
3. Connect to ChefMate AI.
4. Tell ChefMate what ingredients or food products you have.
5. Ask for a recipe, cooking advice, substitutions, or other food-related help.

> **Privacy:** Your API key is entered by you through the application and is not hard-coded into the project.
